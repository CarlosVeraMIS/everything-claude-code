⚖️ MVO Governance Framework

Minimum Viable Ontology: Framework de gobierno semántico usando RDF/OWL para definiciones canónicas de métricas.

1
Extraction & Normalization
Extrae metadata de todas las fuentes (PBI, Tableau, QS, Excel). Normaliza en esquema común: medida → (nombre, DAX/expresión, formato, categoría).
2
Candidate Grouping
Fuzzy matching (70% umbral) agrupa medidas similares. Detecta conflictos: nombres similares, DAX diferente. Genera candidatos para review.
3
Manual Review (Silver)
Business user revisa candidatos en portal. Resuelve conflictos: "Estos son iguales" vs "Estos son distintos". Agrega metadata: categoría, owner, SLA, descripción.
4
Admin Approval (Gold)
Admin certifica medida canónica. Asigna identificador único (MVO ID). Crea RDF/OWL triple: medida ← código SQL/DAX oficial.
5
Publish & Distribute
Publica en Gold layer (OneLake + Semantic Model). Versionado automático + audit trail. APIs exponen definiciones a BI tools.
